# Data Science & Machine Learning Practice

A collection of hands-on projects and exercises exploring data analysis, machine learning, and deep learning using Python.

### Areas Covered
- **Data Analysis:** Data cleaning, preprocessing, EDA, and feature engineering.
- **Machine Learning:** Classification, regression, clustering, and model evaluation.
- **NLP:** Text preprocessing and sentiment classification using TF-IDF.
- **Deep Learning:** Neural networks and CNN fundamentals.
- **Model Deployment:** Basic model integration with Flask.

### Technologies
Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · TensorFlow/Keras · PyTorch · Flask

### Purpose
This repository demonstrates my practical learning and experimentation with core Data Science and Machine Learning concepts. It complements my academic and applied AI/ML project experience.

*Note: This is a learning and practice repository, not a production-ready ML system.*
